# Exercise Set 2 — Computational Week

This folder contains the Week 2 practical work for the mini-course **Machine Learning, Deep Learning, and AI for Astrophysics**.

## Monday — Slots 7–8

`01_catalog_ml_and_mlp.ipynb`

- tabular astrophysical ML workflow;
- class imbalance and appropriate metrics;
- threshold selection;
- survey/source shortcut diagnosis;
- classical baselines;
- first PyTorch multilayer perceptron.

## Wednesday — Slots 9–10

`02_spectra_and_time_series.ipynb`

- physically motivated spectral features;
- 1D CNNs for spectra;
- time-series feature baselines;
- temporal CNNs;
- representation and ablation experiments.

## Friday — Slots 11–12

`03_polarimetry_and_miniproject.ipynb`

- q/u versus p/chi representations;
- periodic angle encoding;
- circumstellar-disk geometry inference;
- cross-source robustness;
- Monte Carlo measurement-uncertainty propagation;
- advanced anomaly-detection discussion;
- seven final mini-project options, including the polarimetry project.

Each notebook is also exported to Markdown for convenient reading on GitHub. The notebooks are deliberately self-contained and create synthetic teaching datasets, so students can run the complete workflow before adapting it to real astrophysical datasets.
