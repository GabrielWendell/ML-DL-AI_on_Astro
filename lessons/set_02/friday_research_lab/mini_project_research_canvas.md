## Minimum Viable Experiment

Define exactly:

- **one split**
- **one baseline**
- **one main model**
- **one primary metric**
- **one diagnostic figure**

Then write the first five notebook cells you expect to execute.

## Three-minute pitch

1. Scientific question.
2. Data and representation.
3. Baseline and main model.
4. Validation and metric.
5. Main failure mode.
6. Decisive result.
7. Optional extension, only if time remains.

## Peer-review question

Another group must ask one question that forces a design decision to be revised.
